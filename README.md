# سیستم چندعاملی شرکت مجازی هوش مصنوعی

## ساختار

- **ربات ادمین** (`@Adghjxjjugikyhjjnbot`): ارتباط با مشتری‌ها، دریافت سفارش
- **ربات مدیریت** (`@Mejdhskxndjdkskjbot`): فقط برای صاحب شرکت (@MBK_1)
- **کانال**: @mbkwebsite

## امکانات

- پاسخ خودکار به مشتری و ثبت سفارش
- گزارش لحظه‌ای سفارشات به ربات مدیریت
- تولید محتوا خودکار هر ۳۰ دقیقه در کانال
- دستورات مدیریت: `/status` `/orders` `/post`

## اجرا (رایگان)

### روش ۱: Replit (ساده‌ترین)

1. برو به [replit.com](https://replit.com) و اکانت بساز
2. پروژه جدید Python بساز
3. فایل‌های این پوشه رو آپلود کن
4. در Secrets این دو تا رو اضافه کن:
   - `ADMIN_BOT_TOKEN`
   - `MANAGER_BOT_TOKEN`
5. Run بزن

### روش ۲: Railway / Render

همین کد رو دیپلوی کن (رایگان در پلن رایگان).

### روش ۳: سیستم خودت

```bash
pip install -r requirements.txt
python main.py
```

## دستورات ربات مدیریت

- `/start` - شروع
- `/status` - وضعیت شرکت
- `/orders` - لیست سفارشات
- `/post` - ارسال دستی محتوا به کانال
- `/help` - راهنما
